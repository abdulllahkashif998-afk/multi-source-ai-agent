# Final test cases and evidence register

Compiled from retained reports and the recorded implementation runs on 28 October 2026. This is a documentation consolidation; no new application, browser, database or live-provider tests were executed for this document.

## How to read results

- **Passed** means the stated check succeeded using the stated method and version/run. It does not certify every feature or current deployment.
- **Failed** preserves an observed failure or measured quality miss. A later automated fix is a separate entry; it does not rewrite the failed live observation.
- **Not Tested** means the specified manual/live acceptance has no retained successful verification, or human review remains incomplete. Automated coverage elsewhere does not turn it into a manual pass.
- **Automated — Codex** distinguishes mocked provider/browser responses, real PostgreSQL tests, real Ollama retrieval and scripted workflows. A browser controlled by Codex is automated, even when it uses the real backend.
- **Live AI** means real provider HTTP calls occurred; it does not imply human semantic review or a 25-case accuracy result.
- **Manual — user confirmation** records only the scope the user explicitly confirmed. It has no invented timestamp, screenshot or request ID.

Evidence links point to dated retained reports or test source. Historical test counts differ because the suite grew. Latest recorded follow-up: 222/222 disposable-database tests; standard suite 214 passed/eight optional skips; Datasets browser 20/20; TypeScript, ESLint and Webpack passed. These are regression results, not AI accuracy percentages.
